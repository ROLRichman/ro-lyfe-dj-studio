HARDWARE & REMOTE SETUP

Universal controller connection

A USB or supported Bluetooth MIDI controller can control the laptop DJ desk through the browser's MIDI connection. This is different from opening the studio on a second phone as a wireless remote.

NO CONTROLLER CONNECTED
No MIDI devices listed yet. Connect a controller and choose CONNECT MIDI.
LAPTOP · PHYSICAL CONTROLLER

Connect a MIDI controller

  1. Plug the controller into the laptop with its USB cable, or pair a supported Bluetooth MIDI device.
  2. Open RO’Lyfe in a supported desktop browser over HTTPS and press CONNECT MIDI.
  3. Allow the browser's MIDI permission. Select a software control, press LEARN CONTROL, then move the matching knob, fader or pad.
  4. Repeat for each control. MIDI mappings are saved in this browser on this laptop.
PHONE / TABLET · WIRELESS REMOTE

Use a second device as a remote

Not paired in this build yet. A second device needs a secure one-time pairing code/QR, a shared session, and a real-time network bridge back to the laptop. Simply opening the same website on two devices will not link their controls.

NETWORK REMOTE · PLANNED, NOT ACTIVE
Touch feedback: buttons, pads, knobs and sliders light up when touched; active switches remain visibly selected. AI DJ Coach: planned as a secure server-side assistant, not an enabled browser feature in this build.
Web MIDI is browser-dependent and requires a secure context. Desktop Chrome/Edge are the safest first pilot targets; phone/tablet USB and Bluetooth MIDI availability varies by device and browser. The phone-as-remote feature needs a separate paired-session service.

WEEKEND DJ PILOT · PHONE FIRST, LAPTOP SECOND

1 · Start on the phone

Open RO’Lyfe in the phone browser. Load two local tracks, leave FOLLOW MY MIX on, and work through loading, cue, BPM, Sync, loops, EQ, FX, crossfader and Auto Blend. Confirm the Coach recognizes each action and keeps guiding after the second track loads.

2 · Repeat on the laptop

At home, open the same studio on the laptop and repeat the set. Check the larger display, drag-and-drop crate, radio input, sound effects, recording and any connected DJ controller. Music files saved on the phone do not automatically sync to the laptop; load the tracks on each device for its test.

Use the same two reference tracks on both devices when possible. Note browser, device, track BPM source (manual or tap) and any timing drift. Report what you actually observed—do not mark a feature passed just because its button lit up.

Notes and issues

Known limits: the jog wheel now responds to circular platter movement for track scrubbing and visibly spins during playback; full reverse-audio vinyl scratching is still in the next audio-engine milestone. MIDI support is basic and browser-dependent. Headphone cue routing and universal controller compatibility still need real hardware work. This preview is for testing, not paid gigs.
